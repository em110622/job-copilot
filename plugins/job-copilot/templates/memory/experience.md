# Experience

The single source of truth for what you have done and the value it created. Every CV line, cover-letter sentence, interview story, and LinkedIn post is built from the records here, and nothing else.

Your experience is organised by employment, and within each employment by **forløb**: one record per project, initiative, or engagement. One job usually holds several forløb.

Write field labels in whichever language your own CV uses. The co-pilot translates when an application is in another language, and never adds anything in translation.

## How a forløb record looks

The four core fields are the ones you already use. The optional fields are where the co-pilot will suggest sharpening over time (the `experience-coach` skill); fill them when you have them, skip them when you don't.

```
### Forløb: <title of the project or initiative>
- Period: <from - to>
- Reference: <name(s) who can vouch for this; consent is tracked in contacts.md>

**Responsibility**
- <what you were responsible for, and in which role>

**Goals**
- <goal 1>
- <goal 2>

**Results**
- <result 1, ideally answering goal 1>
- <result 2, ideally answering goal 2>

Optional, add when known:
- Starting point: <why this forløb existed; the problem or the "before">
- My specific part: <the decisions and actions that were yours, beyond the team's>
- Scale: <teams, people, budget, volume, timeline>
- Effect: <what the results changed for the business, customers, or team>
- Evidence: <measured / estimated / qualitative (quote, promotion, reference)>
- Publicity: <public / range only / anonymise / internal only>
- Skills and themes: <tags, so tailoring can find this record>
```
